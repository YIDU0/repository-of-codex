# 工时手账 · 第一阶段开发验证版说明

版本：0.1.0+1。阶段：工具链、最小工程与平台风险验证。

本说明随 GitHub Actions 构建产物一同分发。当前版本只供开发测试，尚未实现正式工时记录、时薪配置、工资计算、统计、完整备份恢复或每日提醒业务。

## 可以查看和测试的内容

- 中文奶油手账风页面骨架：首页、月历、统计、设置。
- 首页右上角实验图标中的“开发版平台验证”。
- 独立 SQLite 计数器、验证 JSON 文件保存/选择、单条测试通知的权限及排程/查询/取消。

验证页不写入工资记录；计数器与验证 JSON 不是正式账本或备份格式。

## 验证状态与已知限制

- 云端本地基线：静态分析无问题，5 项共享代码测试通过，Android APK 构建成功。
- 软件模拟器已安装 AOT 验证包并显示首页，但系统 UIAutomation 连接超时；文件、通知等设备功能尚未通过验收。
- 4 项原生 Dart 集成用例因 JIT 测试 APK 安装失败而未执行，不能视为通过。
- Android 真机尚未验证。工程声明最低 Android 7.0/API 24，不代表所有系统或厂商设备已验收。
- iOS 仅生成工程，尚未编译、签名或真机验证。APK 不能安装到 iPhone，也不能在 Windows 上作为应用运行。
- 当前这次远端检查和构建是否成功，以对应 GitHub Actions 运行结果为准；构建成功不能代替设备验收。

## 文件与安装

- `worktime-journal-stage1-debug.apk`：正常应用入口，显式启用开发验证页，使用调试签名。
- `SHA256SUMS.txt`：该次 APK 的 SHA-256 校验值。
- `BUILD_INFO.txt`：源代码提交、分支和工作流运行地址。
- `版本说明.md`：本说明。

下载后先解压，再将 APK 传到安卓手机，从文件管理器安装。手机可能要求临时允许该文件管理器安装应用。不同构建机器的调试签名可能不同；如遇签名冲突，先确认旧包中的数据是否需要保留，再处理旧包，不能承诺覆盖安装。卸载会清除本地应用数据。

GitHub 构建产物保留 7 天；过期后需要重新构建。工作流上传范围仅为上述四个文件，不包含签名私钥、个人账本、ADB 状态或 SDK 缓存。

源码分发分支：`codex/stage1-download`。本分支用于第一阶段工程审阅及开发包下载，不代表第一阶段平台验收全部通过，也不代表正式业务 APP 已交付。
